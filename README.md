### Open-Source Plans

**GNSS Spoofing Detection Reproduction and Evaluation Platform | Design and Baseline Preparation**

The planned platform will build on the CU-SDR GPS L1 C/A receiver, with modular implementations of representative spoofing detection methods and validation using public intermediate-frequency datasets such as TEXBAT. Each method will include its paper reference, implementation notes, experiment configurations, results, and an analysis of reproduction discrepancies.

Reproduction under the original paper's conditions and evaluation under a common receiver configuration will be documented separately. Evaluation will cover detection latency, false alarms, missed detections, receiver outputs, and computational cost. Supported methods and validated results will be documented in the project repository.
